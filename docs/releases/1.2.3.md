## Automatic playback advancement

Fix automatic advancement after songs finish in shuffled stream playlists. YouTube now checks local player state to recover missed end events. Both YouTube and Spotify retry failed completion reports, while ignoring duplicate endings and completions from earlier tracks.

Automated checks cover missed endings, completion retries for both providers, repeated-track rotations, and stale completion handling. Typecheck, lint, 71 tests, 33 UI checks, the build and Electron smoke checks passed before release preparation. The Windows release workflow also checks packaged startup and release artifacts. Real-account playback and manual Windows installation, listening and update checks have not been repeated for this release.
