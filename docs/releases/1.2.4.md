## Redesigned music workspace

Encore now has a dark music workspace with warm accents, a compact queue, a persistent Now playing panel and bottom playback controls. Filter requests, personal listening and the stream playlist, open per-track action menus, and see the next eligible song without changing pages.

Playback controls now include seeking, restart, shuffle, repeat, favourite and mute. Seeking checks the current track and playback session. Shuffle changes upcoming stream tracks without changing the saved playlist; disabling repeat lets the remaining stream playlist finish once. The About page no longer displays the release verification notice.

Spotify playback now recovers from stale or offline Encore browser devices, including playback requests returning 404, with bounded reconnect attempts and visible recovery status.

Automated verification covers queue and playlist behavior, provider recovery, guarded seeking and responsive controls. The Windows release workflow runs typecheck, lint, unit tests, UI checks, builds, desktop smoke checks and packaged startup checks, then validates release artifacts and checksums before publication. Real-account Spotify/DRM endurance and manual Windows installation, listening and update checks have not been repeated for this release.
