## Search, presence and desktop polish

This release includes the changes prepared for 1.2.5, which was not published after Windows checks caught a Discord IPC path portability issue. That issue is corrected here.

Song searches now show Spotify and YouTube results with platform labels, artwork and an explicit Add action, so you can choose the version you want before adding it.

Discord Rich Presence can show the current song, artist, artwork and playback time, with buttons for the song and the latest Encore release. Sharing is optional and reconnects when Discord restarts.

Encore now uses a custom title bar with minimise, maximise/restore and close controls, without the native File/Edit/View menu. Provider SDKs load when needed, idle and paused polling is reduced, and playback progress uses lighter updates.

Fixed Spotify resume responses being parsed as JSON, which could leave the play icon and progress frozen even while audio resumed. YouTube setup now shows when a key is configured, retains it when the replacement box is blank, and updates API verification after successful requests. Restored keys show an API check pending; session-only credential storage is labelled explicitly.

Local verification passed typecheck, lint, 119 unit tests, 60 responsive UI checks, the production build and Electron smoke checks. The Windows release workflow repeats automated checks, tests packaged startup, and verifies installer, portable, update metadata and checksums before publication. Manual Windows installation/update checks, live Spotify/YouTube account playback and Discord profile rendering have not been repeated for this release. Authenticode signing is not configured, so SmartScreen warnings are expected.
