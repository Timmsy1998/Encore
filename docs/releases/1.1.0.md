## Changes

- Create multiple independent OBS overlays, each with its own saved design and stable URL.
- Choose horizontal cards or vertical gallery layouts, with optional spinning vinyl artwork, animated equalizer bars and smooth song transitions. Reduced motion is respected.
- Hide platform names and show “Requested by” only for viewer requests. Removed the global Working indicator.
- Enable square Canvas artwork to show the current YouTube video muted and synchronized in OBS, with cover-art fallback. Spotify retains cover art because its public APIs do not expose Canvas videos.
- Plain-text requests prefer Spotify, then artist/YouTube Music audio, then regular YouTube videos. Explicit provider links retain the selected track. YouTube Music preference uses artist/audio metadata from the YouTube API.

Existing overlay URLs and saved settings remain compatible. OBS overlays are visual only: mute Browser sources and capture Encore audio once.
