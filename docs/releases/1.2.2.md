## Up Next and playlist library

Queue / Up Next now has its own page with the current track, viewer requests and who requested them, your personal queue, and a preview of the stream playlist rotation. Requests keep priority after the current track finishes.

Playlists now have a dedicated library page. Playlist contents stay closed until you open a playlist. Reorder playlists and their tracks with drag and drop or labelled keyboard-accessible controls, and manage stream playback, imports, names and shuffle from the library.

Automated checks cover queue previews, saved playlist ordering, real Electron IPC and persistence, and the interface at desktop and scaled narrow sizes. The Windows release workflow also checks packaged startup and release artifacts. Real-account playback and manual Windows installation, listening and update checks have not been repeated for this release.
